# simple-tasks

## Shortcuts

- a: add a new task
- m: modify the highlighted task
- s: change the status of the highlighted task
- d: delete the highlighted task
- ctrl+d: delete all tasks
- f: set which statuses to be shown on the main screen (on app start it is set to 'not started')
 - s: selects all stasuses
 - d: deselects all statuses (if submitted with no selection then the active statuses, like when the app starts
- +: expand all tasks
- -: collapse all tasks
- return: toggle highligthed task
