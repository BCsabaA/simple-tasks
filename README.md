# simple-tasks

## Shortcuts

- a: add a new task
- m: modify the highlighted task
- s: change the status of the highlighted task
- d: delete the highlighted task
- f: set which statuses to be shown on the main screen (on app start it is set to 'not started')
- +: expand all tasks
- -: collapse all tasks
- return: toggle highligthed task
